# RAEL

**Relational Accounting Execution Layer**

> An executable research prototype and reference architecture for relationship-preserving accounting and administrative-state automation.

**Patent pending in Canada — Application No. 3,319,794**

## Current Prototype Status

RAEL is currently implemented as a working Python research prototype and proof-of-concept architecture. It is not yet a production enterprise deployment.

The current public implementation includes:

- a Python core governed execution engine;
- three executable reference modules;
- automated tests and GitHub Actions validation;
- browser-local execution of the repository's Python modules; and
- an interactive public prototype.

The three executable reference applications are:

1. **Settlement Execution** — operational relationship → accounting state;
2. **Cost-to-Financial State Transition** — internal cost state → financially recognizable state;
3. **Net-Worth Administrative State Formation** — financial observation → administrative tax state.
